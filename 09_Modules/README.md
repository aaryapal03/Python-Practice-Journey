
# Python Modules
This folder contains my practice programs on Python modules. Through these examples, I am learning how to import modules, use standard library modules, and create my own custom modules.

# Topics and Files

| Topic | File | What It Covers |
|-------|------|----------------|
| Math Module | math_module.py | Using the math module for mathematical functions and constants |
| Random Module | random_module.py | Generating random values, selecting random items, and shuffling lists |
| OS Module | os_module.py | Exploring the working directory, listing files, and working with paths and folders |
| Custom Module | custom_module.py | Defining reusable functions in my own module |
| Importing Modules | importing_modules.py | Practicing import statements, importing specific names, using aliases, and importing my custom module |

#Learning Goals

- Understand the purpose of modules.
- Import modules using import.
- Import specific functions or constants using from ... import.
- Use aliases with as.
- Perform mathematical calculations using the math module.
- Generate random values using the random module.
- Explore basic operating-system interactions using the os module.
- Create a custom module and use it in another Python file.
