# Python Control Structures

This folder contains my practice programs on Python control structures. These examples help me understand decision-making, repetition, and how to control the flow of a program.

# Topics and Files

| Topic | File | What It Covers |

| If Statement | if_statement.py | Running code when a condition is true |
| If-Else Statement | if_else.py | Choosing between two alternatives |
| If-Elif-Else Statement | if_elif_else.py | Checking multiple conditions |
| Nested Conditionals | nested_if_else.py | Using conditional statements inside other conditional statements |
| For Loop | for_loop.py | Iterating over a sequence or range |
| While Loop | while_loop.py | Repeating code while a condition remains true |
| Break, Continue, and Pass | break_continue_pass.py | Examples showing how break exits a loop, continue skips to the next iteration, and pass acts as a placeholder that does nothing |
| Pattern Programs | patterns.py | Practicing nested loops through star and number patterns |
| Extra Practice | practice_questions.py | Combining conditions and loops to solve additional problems |

# Learning Goals

- Write conditions using if, elif, and else.
- Understand and use nested conditional statements.
- Choose between for loops and while loops.
- Understand the differences between break, continue, and pass.
- Use nested loops to build patterns.
- Apply control structures to solve practice problems.
