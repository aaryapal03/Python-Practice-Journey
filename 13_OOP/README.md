
# Python OOPs
This folder contains my practice programs on Object-Oriented Programming (OOP) in Python. Through these examples, I am learning how to work with classes, objects, constructors, methods, inheritance, polymorphism, encapsulation, abstraction, and other important OOP concepts.

# Topics and Files
| Topic | File | What It Covers |
| Classes and Objects | classes_and_objects.py | Creating classes and objects, accessing attributes and methods |
| Constructor | constructor.py | Using __init__() to initialize object attributes |
| Variables and Methods | variables_and_methods.py | Understanding instance variables, class variables, instance methods, class methods, and static methods |
| Inheritance | inheritance.py | Reusing code through inheritance, method overriding, and using super() |
| Polymorphism | polymorphism.py | Using the same method name in different classes and understanding method overriding |
| Encapsulation | encapsulation.py | Controlling access to data using private attributes and getter/setter methods |
| Abstraction | abstraction.py | Hiding implementation details and using abstract classes with the abc module |
| Composition | composition.py | Creating a has-a relationship by using objects of one class inside another class |
| Property Decorator | property_decorator.py | Using @property, @property_name.setter, and @property_name.deleter for controlled attribute access |
| Practice Questions | practice_questions.py | Applying OOP concepts to solve additional problems |
# Learning Goals

- Understand the meaning of classes and objects.
- Create classes and objects.
- Use constructors to initialize objects.
- Understand instance variables and class variables.
- Write instance methods, class methods, and static methods.
- Understand inheritance and reuse code from parent classes.
- Use method overriding and super().
- Understand polymorphism through method overriding.
- Protect data using encapsulation.
- Hide implementation details using abstraction.
- Understand composition and the has-a relationship.
- Use the property decorator for controlled access to attributes.
- Apply OOP concepts to solve practice questions.
