
# Python Lists

This folder contains my practice programs on Python lists. Through these examples, I am learning how to create lists, access and modify their elements, and work with list methods and built-in functions.

# Topics and files

| Topic | File | What It Covers |
|-------|------|----------------|
| List Creation | list_creation.py | Creating empty lists and lists containing different types of values |
| List Indexing | indexing.py | Accessing and updating elements using positive and negative indexes |
| List Slicing | slicing.py | Extracting portions of a list using start, stop, and step values |
| Nested Lists | nested_lists.py | Creating lists inside other lists and accessing their elements |
| List Methods | list_methods.py | Practicing methods such as append(), extend(), insert(), remove(), pop(), clear(), index(), count(), sort(), reverse(), and copy() |
| Practice Questions | practice_questions.py | Applying list concepts to solve additional problems |

# Learning Goals

- Create lists and understand that lists are mutable.
- Access and update elements using indexing.
- Extract portions of a list using slicing.
- Work with nested lists.
- Add, remove, search for, and rearrange elements using list methods.
- Use built-in functions with lists.
- Understand the difference between list methods and built-in functions.
- Apply list concepts to solve practice questions.
