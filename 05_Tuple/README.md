
# Python Tuples
This folder contains my practice programs on Python tuples. Through these examples, I am learning tuple basics, tuple methods, and how to pack and unpack values.

# Topics and Files

| Topic | File | What It Covers |
|-------|------|----------------|
| Tuple Basics | tuple_basics.py | Creating tuples, accessing elements, slicing, and understanding immutability |
| Tuple Methods | tuple_methods.py | Using count() to count occurrences and index() to find the first matching position |
| Packing and Unpacking | packing_unpacking.py | Packing values into a tuple and unpacking them into variables |
| Practice Questions | practice_questions.py | Applying tuple concepts to solve additional problems |

#Learning Goals

- Create empty, single-element, and multiple-element tuples.
- Access elements using positive and negative indexing.
- Extract portions of a tuple using slicing.
- Understand tuple immutability.
- Use the count() and index() methods.
- Pack values into a tuple and unpack them into variables.
- Apply tuple concepts to solve practice questions.
