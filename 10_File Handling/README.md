
# Python File Handling
This folder contains my practice programs on Python file handling. Through these examples, I am learning how to read, write, and append files, work with binary files, and save and load Python objects using pickle.

## Topics and Files

| Topic | File | What It Covers |
|-------|------|----------------|
| Reading Files | read_file.py | Reading text files using read(), readline(), readlines(), and iteration |
| Writing Files | write_file.py | Creating or overwriting text files using write() and writelines() |
| Appending Files | append_file.py | Adding content to the end of a text file without removing existing content |
| Binary Files | binary_file.py | Reading and writing binary data using binary file modes |
| Pickle | pickle_examples.py | Saving and loading Python objects using pickle.dump() and pickle.load() |
| Practice Questions | practice_questions.py | Applying file-handling concepts to solve additional problems |

## Learning Goals

- Open files using appropriate file modes.
- Read text files using different reading methods.
- Write content to files and understand when existing content is overwritten.
- Append content without removing existing data.
- Use with statements to manage files and close them automatically.
- Understand the difference between text and binary files.
- Read and write binary data using rb and wb modes.
- Save and load Python objects using pickle.
- Apply file-handling concepts to solve practice questions.


# Important Notes

- Check the filenames and paths used in each program before running it.
- Programs that read files require those files to exist first.
- Writing with w or wb mode overwrites existing file content.
- Use disposable sample files when practicing write operations.
- Text examples use text data, while binary examples use bytes.
- Only load pickle files from trusted sources.
- Some programs create or modify files when executed.
