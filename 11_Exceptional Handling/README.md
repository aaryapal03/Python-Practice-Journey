
# Python Exception Handling
This folder contains my practice programs on Python exception handling. Through these examples, I am learning how to handle errors using try-except blocks, work with multiple exceptions, use else and finally, raise exceptions, and create custom exceptions.

# Topics and Files
| Topic | File | What It Covers |

| Try-Except | try_except.py | Handling exceptions using try and except blocks |
| Multiple Exceptions | multiple_exceptions.py | Handling different exception types using separate except blocks or a tuple of exceptions |
| Else and Finally | else_finally.py | Using else for code that runs when no exception occurs in the try block, and finally for cleanup |
| Raise | raise_exception.py | Raising exceptions explicitly using the raise statement |
| Custom Exceptions | custom_exceptions.py | Defining and using custom exception classes |
| Nested Try-Except | nested_try_except.py | Placing a try-except block inside another to handle errors at different levels |
| Practice Questions | practice_questions.py | Applying exception-handling concepts to solve additional problems |

# Learning Goals

- Understand the purpose of exception handling.
- Write try-except blocks to handle errors.
- Handle different exception types appropriately.
- Handle multiple exception types in a single except block.
- Use else and finally with try-except.
- Raise exceptions explicitly using raise.
- Define custom exceptions by inheriting from Exception.
- Work with nested try-except blocks.
- Apply exception-handling concepts to solve practice questions.
