
# Python Dictionaries
This folder contains my practice programs on Python dictionaries. Through these examples, I am learning how to work with key-value pairs, use dictionary methods, and create dictionaries using dictionary comprehension.

# Topics and Files

| Topic | File | What It Covers |
|-------|------|----------------|
| Dictionary Basics | dictionary_basics.py | Creating dictionaries, accessing values, and adding, updating, and deleting key-value pairs |
| Dictionary Methods | dictionary_methods.py | Practicing methods such as get(), keys(), values(), items(), update(), pop(), popitem(), clear(), copy(), setdefault(), and fromkeys() |
| Practice Questions | practice_questions.py | Applying dictionary concepts to solve additional problems |

# Learning Goals

- Create empty dictionaries and dictionaries containing key-value pairs.
- Access values using keys.
- Add, update, and delete dictionary entries.
- Understand that dictionary keys are unique.
- Iterate over keys, values, and key-value pairs.
- Use dictionary methods for common operations.
- Create dictionaries using dictionary comprehension.
- Apply dictionary concepts to solve practice questions.
