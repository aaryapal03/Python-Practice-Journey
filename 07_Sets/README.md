# Python Sets
This folder contains my practice programs on Python sets. Through these examples, I am learning how to create sets, work with unique elements, use set methods, and perform set operations.

# Topics and Files

| Topic | File | What It Covers |
|-------|------|----------------|
| Set Basics | set_basics.py | Creating empty and non-empty sets, understanding unique elements, checking membership, and iterating over sets |
| Set Methods | set_methods.py | Practicing methods such as add(), update(), remove(), discard(), pop(), clear(), and copy() |
| Set Operations | set_operations.py | Performing union, intersection, difference, and symmetric difference, and checking subset, superset, and disjoint relationships |
| Practice Questions | practice_questions.py | Applying set concepts to solve additional problems |

# Learning Goals

- Create sets using set() and curly braces.
- Understand that an empty set is created using set(), not {}.
- Understand that sets contain unique elements and do not support indexing or slicing.
- Check membership using in and not in.
- Add and remove elements using set methods.
- Understand the difference between remove() and discard().
- Perform union, intersection, difference, and symmetric difference.
- Check subset, superset, and disjoint relationships.
- Apply set concepts to solve practice questions.
