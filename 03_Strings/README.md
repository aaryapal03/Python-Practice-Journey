# Python Strings

This folder contains my practice programs on Python strings. Through these examples, I am learning how to access, extract,search, manipulate, and work with text.

# Topics and Files

| Topic | File | What It Covers |
|-------|------|----------------|
| String Indexing | indexing.py | Accessing individual characters using positive and negative indexes |
| String Slicing | slicing.py | Extracting parts of a string using start, stop, and step values |
| String Methods | string_methods.py | Exploring string methods for changing case, trimming whitespace, splitting, joining, replacing text, searching, counting occurrences, and checking string content |
| String Operations | string_operations.py | Practicing concatenation, repetition, membership checks, and string comparisons |
| Practice Questions | practice_questions.py | Applying string concepts to solve additional problems |

# Learning Goals

- Access characters using positive and negative indexing.
- Extract and reverse text using slicing.
- Understand that strings are immutable.
- Explore string methods, including methods for searching and counting.
- Combine, repeat, and compare strings.
- Apply string concepts to solve practice questions.
