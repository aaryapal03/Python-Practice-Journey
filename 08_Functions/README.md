
# Python Functions
This folder contains my practice programs on Python functions. Through these examples, I am learning how to write reusable code, pass arguments, use recursion and lambda functions, and work with map(), filter(), and reduce().

# Topics and Files

| Topic | File | What It Covers |
|-------|------|----------------|
| Basic Functions | basic_functions.py | Defining and calling functions, using parameters, and returning values |
| Types of Arguments | argument_types.py | Practicing positional, keyword, default, and variable-length arguments (*args and **kwargs) in one file |
| Recursion | recursion.py | Writing functions that call themselves, with base cases and recursive steps |
| Lambda Functions | lambda_functions.py | Creating and using small anonymous functions |
| Map, Filter, and Reduce | map_filter_reduce.py | Transforming items with map(), selecting items with filter(), and combining items into a single result with reduce() |
| Practice Questions | practice_questions.py | Applying function concepts to solve additional problems |

# Learning Goals

- Define and call functions using def.
- Understand the difference between parameters and arguments.
- Return values from functions using return.
- Use positional, keyword, default, and variable-length arguments.
- Understand how *args and **kwargs collect arguments.
- Write recursive functions with appropriate base cases.
- Create and use lambda functions.
- Work with map(), filter(), and reduce().
- Apply function concepts to solve practice questions.
